A single out-of-office auto-reply, one line long, written to be the
funniest thing a colleague reads all week — and still a message a real
person would gladly switch on before going away.

## The line

> I'm away until Friday — my emails will be answered in the order they stop mattering.

## How to run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (or to
`$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).

## Gate

- Length: **84 characters** — within the required 1–160 characters.
- Exactly one line, UTF-8 text, no name or signature needed.
